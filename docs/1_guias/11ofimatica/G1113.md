## ¿Qué son las fórmulas?

Las **fórmulas** son el **principal recurso** en una **hoja de cálculo**.

Una fórmula es una expresión que relaciona mediante operadores uno o más valores, que pueden ser valores constantes, celdas, rangos de celdas, o funciones, y devuelve un resultado que aparecerá directamente en la celda que la contiene. 

Una fórmula está compuesta por un signo **=** seguido de la **expresión** que indica la operación a realizar.

Por ejemplo:

$$=A5+B5/C2$$

---
## Tipos de formulas en LibreOffice Calc

Las fórmulas en **LibreOffice Calc** se pueden clasificar en tres tipos:

1. **Fórmulas simples**: Realizan operaciones simples con valores constantes. **Por ejemplo:**

$$=(10*15)/2$$ 

2. **Fórmulas con referencias**: Realizan operaciones simples con referencias a otras celdas y opcionalmente con valores constantes. La referencia se indica introduciendo el nombre de la celda. Por ejemplo:

$$=(A1+B19)*89$$

3. **Fórmulas con funciones**: Realizan operaciones simples con referencias a otras celdas, opcionalmente con valores constantes y con otro tipo de expresiones llamadas funciones. Por ejemplo:

$$=SUMA(A1:A35)/LOG(H10;25)$$

---
## Operadores aritméticos y precedencia

Un **operador** es un símbolo matemático el cual indica que una operación debe llevarse a cabo sobre un número de operandos.

Los operandos pueden ser:

- Números
- Celdas
- Funciones

Los operadores aritméticos son:

:::{csv-table}
:header-rows: 1
:delim: ;
OPERADOR ; SÍMBOLO
Suma ; **+**
Resta ; **-**
Multiplicación ; $*$
División ; **/**
Porcentaje ; **%**
Potencia ; **^**
:::

La **prioridad de los operadores** (también conocida como **precedencia**), son unas reglas que determinan en una operación, que operadores se resuelven primero. El orden de operación es el siguiente:

- Primero se opera el contenido dentro de los paréntesis.
- Luego se opera el contenido de las multiplicaciones y divisiones.
- Finalmente se opera el contenido de las sumas y restas.

---
## Referencias 

Una referencia en **LibreOffice Calc** es una dirección que identifica una celda, un grupo de celdas o una hoja para usar sus datos en una fórmula. Sus tipos principales son relativas y absolutas.

### Referencias relativas

Una **referencia relativa** es una celda cualquiera que se agrega en una fórmula cuyo valor **VARIA** si se aplica un relleno de celdas. Por ejemplo :

$$=A1+B1$$

:::{csv-table}
:delim: ;
:header-rows: 1
      ; A  ; B	 ; C
**1** ; 10 ; 100 ; $=A1+B1$
**2** ; 11 ; 101 ; $=A2+B2$
**3** ; 12 ; 102 ; $=A3+B3$
:::

### Referencias absolutas

Una **referencia absoluta** es una celda cualquiera que se agrega en una fórmula cuyo valor **NO VARIA** si se aplica un relleno de celdas. Para ello es necesario agregar el carácter $ a la fila y a la columna.  Por ejemplo:

$$=A1+\$B\$1$$

La celda **B1**, al aplicar un relleno de celdas vertical en la **columna C**, el valor de dicha celda NO AUMENTA:

:::{csv-table}
:delim: ;
:header-rows: 1
      ; A  ; B	 ; C
**1** ; 10 ; 100 ; $=A1+\$B\$1$
**2** ; 11 ; 101 ; $=A2+\$B\$1$
**3** ; 12 ; 102 ; $=A3+\$B\$1$
:::
