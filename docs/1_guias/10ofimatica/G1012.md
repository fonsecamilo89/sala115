### ¿Qué es LibreOffice Writer?

:::{list-table}
* - ```{figure} ./recursos/G1012/image01.png
    :width: 120
    LibreOffice Writer
    ```
:::

**LibreOffice Writer** es un procesador de textos, compatible con todas las versiones de Microsoft Word y además nos provee de nuevas funcionalidades. Writer le permitirá crear documentos con características como:

- Un correcto formateado de caracteres y párrafos.
- Un uso eficiente de los estilos.
- Auto-texto que le permite reutilizar contenidos con toda comodidad.
- Numeraciones y viñetas.
- Inserción y manejo de imágenes.
- Trabajo con documentos largos esquematizados, con creación de índices.

A continuación se muestra un ejemplo de un documento realizado en LibreOffice Writer:

:::{list-table}
* - ```{figure} ./recursos/G1012/image02.png
    :width: 600
    Hoja de documento LibreOffice Writer
    ```
:::

LibreOffice también puede usarse de forma profesional. Para ello es necesario conocer varias herramientas que permiten hacer que los documentos sean más productivos. Estas herramientas son:

- Uso de tablas para crear formularios con valores que se auto-calculan.
- Creación de secciones en columnas en el documento.
- Creación de diagramas de datos a partir de datos contenidos en tablas.
- Trabajo con cuadros de texto y marcos.
- Establecer referencias, vínculos y enlaces en los documentos.
- Creación de cartas en serie y etiquetas personalizadas para múltiples destinatarios extraídos de una base de datos.
- Asignación de contraseñas para asegurar la integridad de los documentos.
- Personalización de las barra de herramientas, menús y atajos de teclado para mayor productividad.

### LibreOffice Writer Vs Microsoft Word

:::{list-table}
* - ```{figure} ./recursos/G1012/image04.png
    :width: 200
    LibreOffice Writer Vs Microsoft Word
    ```
:::

LibreOffice Writer y Microsoft Word son dos suites de oficina ampliamente utilizadas que ofrecen muchas funcionalidades similares para la creación y edición de documentos. Sin embargo, hay algunas características distintivas de LibreOffice Writer que pueden diferenciarlo de Microsoft Word.

A continuación se muestran algunas funcionalidades de LibreOffice Writer que no están disponibles en Microsoft Word:

- **Licencia de código abierto:** LibreOffice es un software de código abierto bajo la licencia LGPL, lo que significa que es gratuito para descargar, usar, modificar y distribuir libremente. Microsoft Word, en cambio, es parte de Microsoft Office, que es un software comercial con licencia propietaria.
- **Soporte nativo para formatos abiertos:** LibreOffice Writer tiene un soporte nativo robusto para formatos abiertos como ODT (OpenDocument Text), mientras que Microsoft Word generalmente utiliza formatos propietarios como DOCX. Aunque Word puede abrir y guardar archivos ODT, no es su formato nativo.
- **Mayor flexibilidad en la interfaz:** LibreOffice Writer ofrece una interfaz altamente personalizable que puede ser ajustada para adaptarse mejor a las preferencias del usuario. Esto puede incluir la capacidad de personalizar barras de herramientas, atajos de teclado y más, de una manera más flexible que en Microsoft Word.
- **Compatibilidad multi-plataforma:** LibreOffice está disponible para una amplia gama de sistemas operativos, incluidos Windows, macOS y varias distribuciones de Linux. Microsoft Word, aunque está disponible para Windows y macOS, no tiene una versión nativa para Linux.
- **Extensiones y complementos libres:** LibreOffice tiene una comunidad activa que desarrolla extensiones y complementos que pueden ampliar sus funcionalidades básicas. Estos pueden ser descargados e instalados fácilmente para añadir nuevas características a LibreOffice Writer.
- **No requiere suscripción:** LibreOffice Writer y toda la suite LibreOffice no requieren una suscripción para su uso. Esto puede ser una ventaja para aquellos que prefieren no comprometerse con un modelo de suscripción.
